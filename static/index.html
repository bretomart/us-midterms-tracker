Ingested

  • AP results feed (apnews.com): the JSON behind AP's results page, on interactives.apelections.org. Race list, candidate votes, percent of expected vote, the AP's own race calls, and per-race poll closing times. No key; the CDN only checks the referer.
  • civicAPI v2 (civicapi.org): fallback when AP is unreachable. Same fields, no race-call labels.
  • Ten RSS wires (MS NOW, CNN, Fox, NBC, NPR, PBS, CBS, ABC, Politico, The Hill) for headlines, and for state and district exit-poll numbers as outlets publish them.
  • NBC national exit poll (nbcnews.com): the document behind NBC's exit poll page, SSRS interviews for the National Election Pool. Voter-group splits on the U.S. House vote, refetched every five minutes.
  • Closing hours from state election office documents and statutes, cross-checked against the AP state-by-state guide.

Not available

  • AP Elections API: key gated and paid. The public feed behind AP's own results page carries the same numbers, so that is what this reads.
  • Decision Desk HQ: returns HTTP 429 to this client, and its API is paid.
  • State and district exit poll crosstabs: NBC carries them on individual state pages, with no stable per-race feed, so none is scraped. The wire covers them as outlets publish.
  • AP VoteCast: key gated, and no public machine-readable endpoint.

Rules

  • Votes are never averaged across feeds. Where the feed and the published baseline disagree, the banner above names it.
  • A race with no votes shows "no votes yet", never zero.
  • Territories and the synthetic national rollup stay out of the 50-state, 100-seat and 435-seat arithmetic.
  • Exit poll figures are self-reported voter splits from one pollster. They sit beside the tallies and are never added to them or used to call a race.
